# Imported 360 panoramas

Use **Tools > KINO Rotunda > 360 Skybox** to drop in a licensed JPG/PNG/HDR/EXR panorama. The importer creates a separate subfolder for each application, including the source, sky texture/material and import report. This folder currently contains no third-party Athens panorama.

Workflow and validation: `Tools/KinoPanorama/README.md` in the project root.
